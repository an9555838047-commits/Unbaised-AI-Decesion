# Unbiased AI Decision – Fairness Check

## 📌 Project Overview
This project is a prototype application that evaluates fairness in AI-driven decisions.  
It provides a simple GUI where users can input decision data, select fairness criteria, and assign weights to measure bias.  

## 🎯 Problem Statement
AI systems often risk producing biased outcomes.  
This app helps visualize and test fairness metrics (like demographic parity) to ensure decisions are unbiased and transparent.

## ⚙️ Features
- Input decision data through a text area
- Choose fairness criteria (e.g., demographic parity)
- Assign fairness weight (%) to balance decision outcomes
- Evaluate fairness with a single click
- Simple Java Swing GUI for easy interaction
